# Portfólio — Mateus Irineu

Portfólio pessoal de engenharia de software com estética **Minimalista Editorial Dark** (inspirado em Brittany Chiang, Lee Robinson e Paco Coursey), construído com **React 19**, **Vite 8** e **Tailwind CSS 4**.

## ✨ Destaques

- **Split-Screen Editorial Responsivo:** Coluna fixa de identidade e navegação com scroll-spy + coluna fluida de conteúdo técnico.
- **Spotlight Dinâmico:** Iluminação radial suave que acompanha o cursor no fundo `#090d16`.
- **Inspeção de Arquitetura Interativa:** Cada projeto principal (**Kofrim** e **PDFix**) possui um blueprint expansível detalhando o pipeline de dados e decisões de engenharia.
- **Simulador WhatsApp → Gemini 3.8 (Kofrim):** Permite testar cenários reais de mensagem financeira no WhatsApp, extração JSON da IA e resposta persistida no PostgreSQL.
- **Filtro Reativo por Tecnologia:** Ao passar o mouse ou clicar em qualquer tecnologia da Stack, os projetos correspondentes são destacados automaticamente.
- **Command Palette (`Ctrl + K`):** Navegação rápida por teclado, busca de projetos, cópia de e-mail e alternância de idioma (**PT-BR / EN**).

## 🚀 Como Executar

```bash
cd D:\Portfolio
npm install
npm run dev
```

Para gerar a build de produção (pronta para Vercel / Netlify / GitHub Pages):

```bash
npm run build
```
